### 1. [Мониторинг ЭЦН — MVP](https://github.com/Ivan0208/ecn-monitoring)

Публичный pet-project на стыке нефтегазовой экспертизы, Python, веб-кодинга, диагностики оборудования и AI.

**Суть:** система автоматической обработки XLSX-файлов станций управления и диагностики состояния электроцентробежных насосов через веб-интерфейс.

**Реализовано:** парсинг Excel, определение формата ЧРП/КСУ, расчёт диагностических правил, Run Life Index, Streamlit-дашборд, Plotly-графики, рекомендации технологу и AI-эксперт для отчёта по скважине.

**Стек:** Python · pandas · NumPy · SciPy · openpyxl · SQLite · YAML · Plotly · Streamlit · requests

**Результаты:**

- Выстроен процесс управления оптимизационными инициативами с нуля

**Инструменты:** Python · pandas · Jupyter Notebook · Process Mining · Excel · MS Visio

### 4. Диагностика насосного оборудования (Белкамнефть)

Аналитический кейс: в первый месяц работы провёл анализ 8 шурфовых установок на исторических данных за 2 года. Была выявлена причина преждевременных отказов — сквозная коррозия колонны охлаждения.

**Результаты:**
- −8% отказов подземного насосного оборудования

**Инструменты:** Excel · исторические производственные данные
