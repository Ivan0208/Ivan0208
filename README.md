### 1. [Мониторинг ЭЦН — MVP](https://github.com/Ivan0208/ecn-monitoring)

Публичный pet/project на стыке нефтегазовой экспертизы, Python, веб-кодинга, диагностики оборудования и AI.

**Суть:** система автоматической обработки XLSX-файлов станций управления и диагностики состояния электроцентробежных насосов через веб-интерфейс.

**Реализовано:** парсинг Excel, определение формата ЧРП/КСУ, расчет диагностических правил, Run Life Index, Streamlit-дашборд, Plotly-графики, рекомендации технологу и AI-эксперт для отчета по скважине.

**Стек:** Python, pandas, NumPy, SciPy, openpyxl, SQLite, YAML, Plotly, Streamlit, requests.

**Результат:** 148 ролей оптимизированы до 18 при сохранении функциональности.

### 3. Энергоменеджмент и производственная эффективность в нефтегазе

Проекты по внедрению ISO 50001, анализу энергопотребления, расчету KPI, поиску потенциала снижения затрат и оценке экономического эффекта оптимизационных мероприятий.

**Результат:** снижение затрат на электроэнергию добывающих активов на 4% и 5% в разных проектах.

### 4. AI-инструменты для бизнес-аналитиков

Практическое применение LLM и AI-агентов в работе аналитика: Langflow, Prompt Engineering, Roo Code, AI-assisted coding, подготовка воркшопа и выступление на митапе по интеграции AI в бизнес-анализ.
